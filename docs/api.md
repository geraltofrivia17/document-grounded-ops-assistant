# API

Interactive documentation generated by FastAPI is served at `/docs` while the service runs.

## GET /health

Returns 200 when the service is ready, and 503 with a `reason` when it started without a usable provider.

```json
{"status": "ok", "version": "0.1.0", "provider": "openai", "model": "gpt-6-luna",
 "retrieval_mode": "embedding", "as_of": "2026-10-01", "documents": 16,
 "excluded_versions": 3, "chunks": 94}
```

`/health` doesn't call the model provider, so load balancers and Docker health checks can poll it at no cost.

## POST /ask

Request:

```json
{"question": "What mileage rate can I claim for my own car?", "top_k": 5}
```

| Field | Rules |
|---|---|
| `question` | Required. After whitespace is collapsed, 3 to 500 characters, containing at least one letter |
| `top_k` | Optional, 1 to 10. Defaults to `retrieval.top_k` in settings |

Unknown fields are rejected.

Response (200):

| Field | Meaning |
|---|---|
| `request_id` | Same value as the `X-Request-ID` response header |
| `outcome` | `answered`, `insufficient_evidence` or `conflicting_evidence` |
| `answer` | The answer, or why the handbook can't answer |
| `conflict_note` | What each source says when they disagree; otherwise empty |
| `citations` | Validated citations: id, document, version, title, section, origin and passage text |
| `retrieved` | The passages supplied to the model, with rank and score |
| `removed_citations` | Ids the model cited that were unknown or not supplied |
| `generation_skipped` | `true` when no passage matched and the model was not called |
| `model` | Model id reported by the provider |
| `retrieval_mode` | `keyword`, `embedding` or `hybrid` |
| `usage` | Input, cached input, output and reasoning tokens, embedding tokens, estimated cost in USD |
| `timings` | Retrieval, generation and total milliseconds |
| `provider` | OpenAI's request id for the generation call, and the number of retries made for this question |
| `warnings` | For example, a removed citation or a missing price |

Errors use the body and categories described in [architecture.md](architecture.md#errors).

## Examples

`scripts/demo_requests.py` sends a fixed set of questions to a running service and saves each request, its status and the response, unedited, in [docs/examples](examples):

| File | Shows |
|---|---|
| `supported.json` | A cited answer |
| `abstention.json` | A question the handbook does not cover |
| `conflict.json` | Two documents in force that disagree |
| `injection.json` | An instruction in the question that the assistant should not follow |
| `invalid_input.json` | A blank question rejected with 422 |
| `timeout.json` | A provider timeout (server started with `OPS_TIMEOUT_SECONDS=0.001`) |

Recorded on 28 October 2026 with `gpt-6-luna` and embedding retrieval.
